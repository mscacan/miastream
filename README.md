# Mia Stream — free personal media player

Download Mia Stream for free. The Android APK and the macOS app are here. Add your own M3U, Xtream, or Stalker source and watch movies, series, and live broadcasts on this device. There is no built-in list. The app is free and does not ask for a store account.

## Free download

- [Download the Android APK](https://msc.so/miastream.apk)
- [Download the macOS app](https://msc.so/miastream.app)

The macOS file is unsigned. On first launch, right-click the app and choose Open.

## What it does

- Free personal media player for Android and Mac
- Movies, series, and live broadcasts
- M3U, M3U8, Xtream, and Stalker
- Artwork, where you left off, and your list stay on this device
- You add the source

## Use

Open the app, choose Add source, and paste your address. After the list loads, pick a movie, a series, or a live broadcast and play it.

## Development

Flutter 3.47, Dart 3.13. Version 1.0.1. Bundle id `com.mias.stream`.

```bash
flutter pub get
flutter run -d macos
flutter test
flutter build apk --release
flutter build macos --release
```
